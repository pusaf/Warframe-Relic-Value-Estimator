## Warframe Relic Value Estimator
A python terminal application that estimates the expected platinum value of a relic.

### Requirements
- BeautifulSoup4
- requests

Install dependencies using:
```
pip install BeautifulSoup4 requests
```

###Usage
```
python main.py
```
Follow the prompts to use the program. On first run, the program will automatically generate a list of relics (relic_list.txt) for you.
